Working agreements live in the Drive folder **Ways of working**, listed in its **Working agreements register**. Only the Records thread writes them, and only Harry accepts them. Changing one is never silent (WA-004).

When a page and a WA disagree, the WA wins and the page is fixed in a pull request.

## Waiting

Waits are labelled by who they wait on, in Linear's "Waiting on" group: `needs:harry`, `waiting:ci` and `waiting:issue`. Only `needs:harry`, the Linear status Waiting, and a message starting "Needs you:" mean Harry must act.
